בקר מתלה כביסה — צריבת קושחה (שיטת גיבוי, שורת פקודה)
========================================================

הדרך הקלה יותר היא כלי הצריבה בדפדפן (קישור בנפרד).
זו שיטה חלופית להרצה משורת פקודה בווינדוס, למקרה שהדפדפן לא נתמך.

מה יש בתיקייה:
  firmware.bin   - הקושחה המלאה לבקר
  flash.bat      - סקריפט שצורב את firmware.bin ללוח

הכנה (פעם אחת בלבד במחשב):
  1. התקן פייתון מ- https://www.python.org/downloads/
     בזמן ההתקנה סמן "Add python.exe to PATH".
  2. פתח שורת פקודה (cmd) והרץ:
       pip install esptool

צריבה:
  1. חבר את לוח ה-NodeMCU למחשב בכבל USB.
  2. פתח את "Device Manager" בווינדוס, ותחת "Ports (COM & LPT)"
     מצא את המספר של ההתקן (לרוב מופיע כ-"Silicon Labs CP210x"), למשל COM5.
  3. פתח שורת פקודה בתיקייה הזו והרץ (שים את המספר שמצאת במקום COM5):
       flash.bat COM5
  4. המתן להודעה "Done. Flashed successfully".

אחרי הצריבה:
  הבקר מתחיל לנסוע קדימה לבד תוך כמה שניות מהפעלה, לפי הערכים הצרובים בו.
  רשת ה-Wi-Fi "Clothesline-Control" (סיסמה: clothesline) עולה לחמש דקות
  בלבד אחרי כל אתחול, לצורך בדיקה/כיוונון בלבד — התחבר תוך 5 הדקות האלה
  ופתח בדפדפן: http://192.168.4.1
  אחרי 5 דקות ה-Wi-Fi נכבה לגמרי; כדי להתחבר שוב יש לאתחל את הלוח.
