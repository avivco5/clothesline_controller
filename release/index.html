צורב בקר המתלה

עמוד הזה צורב את הקושחה ישירות מהדפדפן לבקר המתלה המסתובב, בלי להתקין שום תוכנה. מספיק כבל USB ודפדפן Chrome או Edge במחשב.

    הצריבה דורשת Chrome או Edge על מחשב (Web Serial API אינו נתמך ב-Firefox/Safari או בדפדפני נייד).
    בפעם הראשונה שמחברים את הלוח, ייתכן שוויndows יתקין אוטומטית מנהל התקן עבור ה-USB-UART (Silicon Labs CP210x) —
    זה עשוי לקחת כמה שניות. עמוד זה משקף גרסת קושחה מסוימת שנצרבה בזמן הפרסום; אם הבקר עודכן מאז, יש לבקש קישור מעודכן.
